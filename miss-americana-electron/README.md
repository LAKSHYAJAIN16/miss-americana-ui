# Miss Americana (Electron)

A modern music player application built with Electron, React, and Vite.

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ and npm
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/miss-americana-electron.git
   cd miss-americana-electron
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server with hot reload:
```bash
npm run dev
```

### Build

Build the application for production:
```bash
npm run build
```

### Package

Create a distributable package:
```bash
npm run make
```

## 🛠 Development Tools

- **Editor**: VS Code with recommended extensions
- **Debugging**: Pre-configured launch configurations for VS Code
- **Linting**: ESLint with React and TypeScript support
- **Formatting**: Prettier integration

## 📁 Project Structure

```
.

│   ├── renderer/       # Renderer process code (React)
│   └── shared/         # Shared code between processes

```
